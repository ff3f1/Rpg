# ТЫ.УРОВЕНЬ — MVP v0.1

Android-прототип игрового ежедневника с локальным хранением данных.

## Реализовано

- Главный экран с 2D-персонажем и игровой комнатой
- Список ежедневных задач: добавить / выполнить / удалить
- XP, повышение уровня и 1 алмаз за каждый уровень
- Игровой магазин: шарф и декор комнаты
- Вода, питание, активность и сон с настраиваемыми ориентирами
- Дневник заметок
- Учёт доходов и расходов в рублях
- Статистика, достижения
- Сохранение состояния в Android WebView LocalStorage; экспорт JSON через системный экран "Поделиться"

## Сборка

Открой каталог в Android Studio (JDK 17, Android SDK 35), либо выполни `gradle assembleDebug` с Android SDK. APK появится по адресу `app/build/outputs/apk/debug/app-debug.apk`.

Это **MVP для демонстрации**, без синхронизации, облака, устройств, учётных записей и античит-механик. Задачи привязаны к текущей дате и не переносятся автоматически; цели по воде/питанию не являются медицинскими советами.
